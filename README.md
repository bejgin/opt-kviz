# Definitnost na první pohled

Interaktivní kvíz na určování definitnosti matic bez počítání (předmět B0B33OPT Optimalizace, FEL ČVUT).

**Spustit:** https://bejgin.github.io/opt-kviz/

Procvičuje: diagonální matice, znaménka na diagonále, nuly na diagonále, 2×2 přes determinant, nesymetrické matice, BᵀB a 3×3 Sylvestrovo kritérium. Značení podle skript T. Wernera *Optimalizace*.

Připravil Tonda Šmída.
