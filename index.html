Úspěšnost podle triku

TrikSprávně
Přehled triků
  • Diagonální matice – xTAx = d₁x₁² + … + dₙxₙ², definitnost čteš ze znamének dᵢ.
  • Diagonála má + i − – f(eᵢ) = aᵢᵢ, takže forma nabývá obou znamének ⇒ indefinitní.
  • aₖₖ = 0 a v jeho řádku nenulový prvek – podmatice 2×2 má det = −aₖⱼ² < 0 ⇒ indefinitní.
  • Nulový řádek i sloupec – proměnná ve formě nefiguruje ⇒ nejvýš semidefinitní; rozhoduje zbytek.
  • 2×2 – det < 0 indef.; det > 0 a a₁₁ > 0 PD, a₁₁ < 0 ND; det = 0 semidefinitní (znaménko diagonály).
  • Nesymetrická A – rozhoduje ½(A + AT), ne vlastní čísla A.
  • BTB – xTBTBx = ‖Bx‖² ≥ 0; PD právě když jsou sloupce B lineárně nezávislé.
  • 3×3 – Sylvester: PD ⟺ D₁, D₂, D₃ > 0; ND ⟺ D₁ < 0, D₂ > 0, D₃ < 0. Symetrické úpravy: pivoty dₖ = Dₖ/Dₖ₋₁.
